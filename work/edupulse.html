01 / Collaborative Project Scope

EduPulse was built as a multi-developer team initiative to tackle administration inefficiencies in primary and secondary schools. The application provides dedicated views and capabilities for school owners, teachers, students, and parents.

As the Backend Lead, I was specifically responsible for architecting the relational database schema, authoring the RESTful API endpoints, and implementing token-based authentication with role-based access control (RBAC).

02 / Core Backend Responsibilities

Authentication & RBAC Secured JWT session workflows with distinct permission gates for administrators, instructors, and student/parent accounts.
Student Records API Comprehensive endpoints for profile management, class enrollment mappings, attendance records, and term-by-term grade entry.
Database Modeling Structured relational MySQL schema maintaining data integrity across academic years, terms, courses, assessments, and grade point averages.
Frontend Integration Coordinated closely with frontend engineers to define consistent JSON payload contracts and error handling patterns.
