TConnect VTU & Utility Billing Engine

An automated digital infrastructure built to process high-frequency virtual top-ups, electricity utility bills, data subscriptions, and multi-network telecom services with sub-second wallet reconciliation.

Core Role Solo Full-Stack Engineer & Architect
Stack Laravel (PHP), MySQL, REST APIs, JS
Historic production metric 3,000+ Verified Transactions
Service status Production platform offline

01 / The Challenge & Problem Space

In the Nigerian telecom ecosystem, Virtual Top-Up (VTU) platforms face unpredictable aggregator latency, network drops, and customer disputes when transactions fail midway.

The goal was to build a resilient service layer capable of handling wallet top-ups, dispatching API requests to telecommunication gateways, receiving asynchronous verification webhooks, and preventing double-debits through rigorous database transaction boundaries.

02 / System Architecture & Transaction Flow

Every transaction adheres to an explicit state lifecycle. Funds are locked in MySQL within an isolated transaction before calling external providers.

03 / Key Implementation Decisions

Wallet Ledger System Engineered with row-level transaction locks in MySQL to prevent race conditions during rapid concurrent requests.
Webhook Ingestion Equipped with HMAC signature verification and idempotency keys to ensure vendor status updates are processed exactly once.
Automated Failover Provider routing that redirects orders to backup telecommunication gateways if primary API response times exceed thresholds.
Administrative Control Comprehensive back-office panel providing live transaction logs, automated ledger reconciliation, and manual dispute resolution.

04 / Real-World Outcome

Before the service went offline, TConnect processed more than 3,000 real transactions across MTN, Airtel, Glo, 9mobile, DStv, GOtv, and electricity providers. The platform included wallet-ledger safeguards and automated payment verification.
